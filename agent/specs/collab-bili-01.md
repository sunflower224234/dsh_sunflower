# 架构任务规格书：打通 QQ 银狼 B站视频秒级省流与协同工作流

- **任务编号**: `collab-bili-01`
- **任务目标**: 为 QQ 银狼机器人打通 B 站视频链接的秒级省流与视频特征提炼能力
- **受限目标文件**:
  - `<<<协作桥目录>>>\bridge\bili-summary.mjs`
  - `<<<数据目录>>>\银狼人设提示词-QQ精简版.md`

---

## 一、背景与问题定义
用户在 DSH 运行的 QQ 聊天机器人（使用 `qq-yinlang` 银狼预设，工作区 `<<<工作区>>>`）经常收到群友发来的 B 站视频链接（BV 号或 b23.tv 短链），群友会问“这视频讲了啥”、“总结一下”、“省流”。目前银狼人设写的是‘取不到就直说取不到’，且缺乏执行脚本。

## 二、架构设计与安全约束（严格遵守 DSH 的安全建议）
1. **安全隔离（确定性解析，绝不注入未知脚本）**：
   - 编写 `<<<协作桥目录>>>\bridge\bili-summary.mjs` 作为确定性的 Node 脚本，输入必须经正则严格校验（仅允许合法 BV 号或 B 站 URL），避免群友注入恶意指令；
   - 依赖本地已写好的 `<<<协作桥目录>>>\bridge\bili-parser.mjs` 获取元数据、字幕及轻量流；
2. **两级省流输出标准**：
   - 如果有字幕：输出标题、UP主、时长、300字以内的【太长不看·核心观点】、以及核心【时间轴导航】；
   - 如果无字幕：输出标题、UP主、时长、简介摘要，并附一句：`无字幕轨。若需纯视觉画面理解，可交由协同总线处理。`
3. **银狼人设提示词（热重载）更新**：
   - 文件路径：`<<<数据目录>>>/银狼人设提示词-QQ精简版.md`
   - 修改 `# 关于链接和视频` 章节：
     - 单纯发链接不问问题：依然原样回发 + 吐槽一句；
     - 群友明确要求“讲了啥 / 总结 / 省流 / 看了说说”：执行 `node <<<协作桥目录>>>\bridge\bili-summary.mjs "<链接>"`，拿到结果后用银狼一贯慵懒随性、爱吐槽的口吻将要点甩在群里。

## 三、验收命令
```bash
node <<<协作桥目录>>>\bridge\bili-summary.mjs "BV1xx411c7mD"
```
确保输出格式优雅、不报错、耗时在 1 秒以内。
